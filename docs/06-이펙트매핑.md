# 이펙트 매핑 (게임 상황 ↔ pixelfx)

> **중요:** 아래 이펙트 id는 pixelfx README의 카테고리·이름을 보고 추정한 것이다.
> 실제 파일명은 pixelfx 저장소의 `docs/CATALOG.md`와 `src/fx/<category>/` 폴더로 **반드시 확인**하고, 다르면 이 표를 고친다. (작업 M1-2)

pixelfx 기본 사용법:
- 단독 이펙트: `createFx(module, { x, y, flip, angle, seed, palette })`
- 캐릭터 동작 포함: `createAct(module, { x, y })` — 시전 동작, 타격 정지, 화면 흔들림
- 색 바꾸기: `palette` = 어두운 색 → 밝은 색 순서의 hex 배열
- 엔진 밖에서 쓸 땐: `node tools/render.mjs <id> --sheet` → PNG + JSON 스프라이트 시트

## 4. 새 이펙트가 필요할 때

pixelfx 스킬로 직접 만든다. 예시 프롬프트:
- "pixelfx로 '별가루 반짝임' 이펙트를 만들어줘. 노란·흰 팔레트, 0.6초, 루프 아님. 세 가지 버전 만들고 가장 좋은 거 골라줘"
- "서리호수 마을용으로 얼음 위에 등불이 흔들리는 루프 이펙트 만들어줘"

만든 이펙트는 `client/src/fx/custom/`에 두고 이 표에 추가한다.
