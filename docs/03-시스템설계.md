# 시스템 설계 (게임 규칙과 수치)

> 수치는 초안이다. 바꿀 때는 이 문서와 서버의 `game-balance.yml`을 함께 고친다.
> **모든 판정(보상, 확률, 수치 변경)은 서버에서** 한다. 클라이언트는 결과만 보여 준다.

## 1. 학생(플레이어)

| 항목 | 초기값 | 범위 | 비고 |
|---|---|---|---|
| 별가루 | 100 | 0 ~ 999,999 | 음수 불가 |
| 기력 | 100 | 0 ~ 100 | 수업·훈련에 소모, 시간·쉼터로 회복 |
| 주 원소 | 가입 시 선택 | FIRE / FROST / (NATURE / STORM) | 변경 불가 |

### 기력 회복
- 자연 회복: 5분마다 +1 (서버가 `lastEnergyUpdatedAt` 기준으로 접속 시 계산 — 스케줄러 사용 안 함)
- 온실 쉼터: 30초 앉아 있기 1회당 +10, 하루 5회

## 2. 마법

### 2.1 마법 목록 (MVP)

| 코드 | 이름 | 원소 | 단계 | 해금 숙련도 |
|---|---|---|---|---|
| FIRE_1 | 불씨 튕기기 | 불 | 1 | 0 |
| FIRE_2 | 화염구 | 불 | 2 | 30 |
| FIRE_3 | 불꽃 회오리 | 불 | 3 | 70 |
| FROST_1 | 서리 숨결 | 서리 | 1 | 0 |
| FROST_2 | 얼음 창 | 서리 | 2 | 30 |
| FROST_3 | 서리 폭발 | 서리 | 3 | 70 |

### 2.2 숙련도
- 원소별 0~100
- 수업 미니게임 결과로 상승: `점수등급 S/A/B/C` → `+8 / +5 / +3 / +1`
- 주 원소면 상승량 ×1.5 (내림)
- 수업 1회 기력 15 소모

### 2.3 수업 미니게임 (MVP 1종: "룬 따라 그리기")
- 화면에 룬 경로가 나타나면 마우스로 따라 그림
- 클라이언트는 **정확도(0~1)와 소요 시간**만 서버에 보냄
- 서버가 등급 계산: 정확도 ≥0.9 & 시간 ≤10초 → S, ≥0.75 → A, ≥0.5 → B, 그 외 C
- 치트 방지: 세션 시작 시 서버가 `lessonSessionId` 발급, 시작~종료 시간이 3초 미만이거나 60초 초과면 무효. 같은 세션 중복 제출 불가

### 2.4 보상
| 등급 | 별가루 |
|---|---|
| S | 30 |
| A | 20 |
| B | 10 |
| C | 5 |

## 3. 펫

### 3.1 상태
| 필드 | 범위 | 설명 |
|---|---|---|
| stage | EGG / BABY / ADULT | 성장 단계 |
| hunger | 0~100 | 100이 배부름. 1시간에 -5 (접속 시 계산) |
| affection | 0~100 | 먹이·쓰다듬기로 상승 |
| str / agi / mag | 0~999 | 훈련으로 상승 |

### 3.2 성장
- EGG → BABY: 알 획득 후 실제 시간 10분 경과 + "부화" 버튼
- BABY → ADULT: str+agi+mag 합계 ≥ 60 그리고 affection ≥ 50

### 3.3 행동
| 행동 | 비용 | 효과 | 제한 |
|---|---|---|---|
| 먹이 주기 | 먹이 아이템 1 | hunger +30, affection +2 | hunger 100이면 불가 |
| 쓰다듬기 | 없음 | affection +1 | 하루 10회 |
| 훈련 | 기력 10 | 선택 능력치 +2~+5 (펫 원소 특기 능력치는 +1 보너스) | hunger < 20이면 불가 |

- 훈련 실패 확률 10% (affection 50 이상이면 5%). 실패 시 능력치 변화 없음, 기력은 소모
- 랜덤은 서버의 `RandomProvider` 인터페이스로 주입 → 테스트에서 고정값 사용

## 4. 기숙사

### 4.1 방
- 크기 10×6 타일, 학생당 1개
- 가구 배치 데이터: `{ itemId, x, y, rotation(0/90/180/270) }` 목록

### 4.2 배치 저장 검증 (서버)
1. 모든 가구가 방 범위 안
2. 서로 겹치지 않음 (회전 반영한 footprint 기준)
3. 같은 가구를 보유 수량보다 많이 배치하지 않음
4. 실패 시 400 + 어떤 규칙을 어겼는지 코드 반환 (`OUT_OF_BOUNDS`, `OVERLAP`, `NOT_OWNED`)
- 저장은 **전체 덮어쓰기**(PUT). 낙관적 락(`version`)으로 동시 저장 충돌 방지

### 4.3 가구 (MVP 15종 예시)
침대, 책상, 의자, 책장, 화분, 러그(2×2), 램프, 창문 커튼, 옷장, 수정구 장식, 원소 깃발 ×4(마을별), 별 모빌, 소파(2×1)

## 5. 상점

| 상점 | 위치 | 판매 |
|---|---|---|
| 잿불 대장간 | 잿불 언덕 | 불 테마 가구, 펫 먹이 |
| 서리 공방 | 서리호수 | 서리 테마 가구, 펫 먹이 |
| 로살린 가구점 | 기숙사 | 공용 가구 |
| 돌봄소 | 돌봄소 | 펫 알(1인당 MVP 최대 2마리) |

- 구매 트랜잭션: 잔액 확인 → 차감 → 인벤토리 증가가 **한 트랜잭션**. 잔액 부족 시 롤백
- 동시 구매 대비: 학생 별가루 차감 시 낙관적 락 또는 조건부 UPDATE(`WHERE stardust >= :price`)

## 6. 일일 퀘스트

- 매일 04:00(Asia/Seoul) 기준으로 갱신, 3개 지급
- 퀘스트 풀: 수업 N회, 펫 먹이 N회, 가구 배치 저장 1회, 쉼터 휴식 N회
- 완료 시 별가루 15, 3개 모두 완료 시 추가 30
- 진행도는 각 행동 서비스가 도메인 이벤트(`LessonCompleted`, `PetFed` …)를 발행 → 퀘스트 리스너가 집계

## 7. 연습장 (이펙트 시연)

- 배운 마법을 허수아비에게 써 보는 공간. 보상 없음, 서버 통신 없음
- pixelfx `createAct`로 시전 동작·타격 정지·화면 흔들림까지 재생
