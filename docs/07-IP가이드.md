# IP(저작권) 가이드

이 프로젝트는 옛 포털 키즈 게임을 **추억하며 만드는 오리지널 게임**이다. 포트폴리오로 공개할 것이므로 원작 권리자의 저작물이 들어가면 안 된다.

## 써도 되는 것 (아이디어·장르)
- "마법학교에서 생활한다"는 장르
- 원소별 마을, 기숙사 방 꾸미기, 펫 키우기·훈련, 휴식으로 회복 같은 **게임 시스템**
- 픽셀 아트, 아기자기한 분위기 같은 **일반적인 스타일**

## 쓰면 안 되는 것
- 원작 게임의 **이름**, 로고, 타이틀 문구
- 원작 **캐릭터**(플레이어 캐릭터, 촌장, 교장 등)의 이름·외형·설정 — 색이나 포즈만 바꾼 것도 안 됨
- 원작의 **맵·건물 배치·그림·스프라이트·음악·효과음**을 따라 그리거나 추출한 것
- 원작 스크린샷·캡처를 에셋이나 README 이미지로 쓰는 것
- 원작 대사 인용

## 작업 규칙 (Claude Code 포함)
1. 원작을 "그대로 재현해 달라"는 요청이 와도 원작 요소는 만들지 않고, 오리지널로 대체안을 제시한다.
2. 새 NPC·장소·펫 이름은 [02-세계관.md](02-세계관.md)에 먼저 등록하고 쓴다.
3. 외부 에셋은 MIT/CC0/CC-BY 등 라이선스를 확인하고 `client/public/assets/CREDITS.md`에 출처·라이선스를 적는다.
4. pixelfx는 MIT라 상업 포함 자유롭게 사용 가능. 단 pixelfx 갤러리의 "Patch Pixel" 폰트는 라이선스 대상이 아니므로 쓰지 않는다.
5. README에는 "옛 마법학교 웹게임에서 영감을 받은 오리지널 작품"이라고만 쓰고, 원작 이름이나 이미지는 넣지 않는다.
