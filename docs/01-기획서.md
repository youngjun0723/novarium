# 노바리움 마법학교 — 게임 기획서

> 버전 0.1 · 2026-11-20 · 작성: youngjun
> 어린 시절 즐겼던 "포털 사이트 마법학교 커뮤니티 게임"의 **감성**을 오마주한 **완전 오리지널** 웹게임.

## 1. 한 줄 소개

원소 마을 출신의 신입생이 되어 **마법을 배우고, 기숙사 방을 꾸미고, 펫을 키우며** 학교 생활을 하는 2D 픽셀 웹게임.

## 2. 기획 의도

| 목적 | 내용 |
|---|---|
| 추억 | 2000년대 포털 키즈 게임의 "학교에서 생활한다"는 느낌 — 마을 탐험, 방 꾸미기, 펫 돌보기 |
| 학습 | Spring Boot 백엔드 설계·구현 경험 (인증, 도메인 설계, 트랜잭션, 테스트) |
| 포트폴리오 | 게임이라 시연하기 쉽고, 백엔드 로직(펫 성장, 아이템, 배치 저장)을 설명하기 좋음 |
| 도구 실험 | pixelfx(픽셀 이펙트) + ECC(Claude Code 작업 하네스) 활용 |

## 3. 타깃 & 플랫폼

- **플랫폼**: PC 웹 브라우저 (모바일은 2차 목표)
- **해상도**: 내부 픽셀 해상도 320×180, 화면에 정수배 확대 (`image-rendering: pixelated`)
- **플레이 타임**: 하루 10~20분 접속형 (일일 퀘스트·펫 돌보기)
- **대상**: 본인 + 지인, 포트폴리오 열람자

## 4. 핵심 재미 (Core Loop)

```
접속 → 일일 퀘스트 확인 → 수업(미니게임)으로 마법 숙련도 ↑ → 별가루 획득
   → 상점에서 가구·펫 용품 구매 → 기숙사 꾸미기 / 펫 훈련 → 다음 날 접속
```

세 가지 기둥:
1. **배우기** — 원소 마법을 단계별로 익히고, 연습장에서 이펙트와 함께 써 본다.
2. **꾸미기** — 기숙사 방을 그리드 위 가구로 꾸미고 저장한다.
3. **돌보기** — 알에서 펫을 부화시키고 훈련해 성장시킨다.

## 5. 주요 콘텐츠

### 5.1 캐릭터
- 원작처럼 고정 캐릭터 중 고르는 방식이 아니라, **직접 만드는 아바타**: 이름 + 출신 원소 마을 + 외형 프리셋(머리/로브 색).
- 출신 마을이 **주 원소**가 되어 해당 원소 마법 숙련도 보너스.

### 5.2 장소
| 장소 | 역할 | MVP |
|---|---|---|
| 노바리움 본관 | 중앙 허브, 학교장, 게시판(일일 퀘스트) | ✅ |
| 원소 마을 ×4 | 출신지·수업 장소·마을별 상점 | 2곳 ✅ / 2곳 후속 |
| 기숙사 별채 | 내 방 꾸미기 | ✅ |
| 온실 쉼터 | 기력 회복 (원작의 '사우나' 역할을 오리지널로 대체) | ✅ |
| 동물 돌봄소 | 펫 부화·훈련 | ✅ |
| 별빛 도서관 | 마법 도감, 업적 | 후속 |
| 시험의 탑 | 층별 도전 콘텐츠 (원작에서 못 열린 "3층"의 한을 여기서 푼다) | 후속 |

### 5.3 마법
- 원소 4종 × 단계 3개 = 12개 마법 (MVP: 2원소 × 3 = 6개)
- 숙련도 0~100. 수업 미니게임으로 상승, 단계 해금 조건
- 시전 연출은 pixelfx 이펙트 → [06-이펙트매핑.md](06-이펙트매핑.md)

### 5.4 펫
- 알 → 아기 → 성체 3단계. 원소 성향을 가짐
- 수치: 배고픔, 친밀도, 능력치(힘/민첩/마력)
- 훈련: 기력 소모 → 능력치 상승 (실패 확률 있음)

### 5.5 기숙사
- 10×6 타일 방, 가구는 1×1 ~ 2×2
- 배치·회전·삭제, 저장 시 서버 검증(겹침·범위·보유 수량)
- 다른 학생 방 구경(방문) — 후속

### 5.6 재화
- **별가루**: 유일한 재화. 수업·퀘스트로 획득, 상점에서 소비
- 유료 재화 없음

## 6. 범위 (MVP 정의)

MVP 완료 기준 = "아바타 생성 → 본관 → 마을 2곳 수업 → 별가루로 가구 구매 → 방 꾸미고 저장 → 펫 부화·훈련 1회"가 한 계정으로 끊김 없이 동작.

| 포함 | 제외(후속) |
|---|---|
| 회원가입/로그인 | 소셜 로그인 |
| 아바타 생성 | 실시간 멀티플레이(채팅·같이 걷기) |
| 원소 마을 2곳 + 본관 + 기숙사 + 쉼터 + 돌봄소 | 마을 3·4, 도서관, 시험의 탑 |
| 마법 6종, 수업 미니게임 1종 | 대전 PvP |
| 가구 15종, 펫 2종 | 방 방문, 랭킹 |
| 일일 퀘스트 3종 | 이벤트 시스템 |
